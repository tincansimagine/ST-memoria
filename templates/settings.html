사서에게 정정 요청 — 날짜·기록·요약·인물 설정을 대화로 고치기

읽기 전용 질문이 아니라 실제 기록을 고치는 채팅입니다. 예: "지금 11월인데 3월로 바꿔줘", "그 요약 틀렸어, ○○가 아니라 △△였어", "서사시계 2주가 아니라 3주야", "인물 설정 추가해줘". 사서가 바꿀 내용을 먼저 보여주면, 확인 버튼을 눌러야 실제로 반영됩니다.

초기화
작동 방식 — AI 응답이 끝날 때마다 그 턴을 자동으로 기록해 구조화된 기억으로 보관하고, 매 턴 현재 대화와 관련 있는 기억만 골라 토큰 예산 안에서 주입합니다.
스와이프·편집·삭제·재생성 — 해당 턴(또는 지워진 마지막 턴)의 파생 기억은 자동으로 무효화되고, 새 응답이 오면 다시 기록됩니다. 재생성을 자주 쓰는 경우에도 옛 턴 기록이 같이 사라지지 않도록 v1.4.1에서 정리 로직을 보강했습니다.

기억 브라우저

고정(📌)한 기억은 토큰 예산 안에서 우선 주입됩니다. 책 아이콘으로 대화 원문을 확인할 수 있습니다.

관계선

한 사람이 다른 한 사람을 지금 어떻게 대하는지 — 단계, 근거가 된 장면, 부르는 말, 아직 말하지 못한 것. 관계가 실제로 움직인 장면에서만 기록되고, 지나온 단계가 함께 남아 AI가 감정선을 건너뛰거나 되돌리지 않게 합니다.

자료실

원작 소설·설정 문서를 붙여넣어 두면, 매 턴 지금 장면과 관련된 대목만 골라 배경 참고로 주입합니다. 채팅에서 확정된 사실이 항상 우선하며, 토큰 예산이 부족하면 가장 먼저 줄어듭니다.

기본 설정
세트

기본

원문·요약에 이미 나온 비밀까지 가리지는 않습니다. 장부를 직접 고정했다면 고정을 해제해야 새 방식이 적용됩니다.

최근 메시지 보존 수는 "자동 숨김"을 켰을 때만 쓰입니다. 요약은 이 값과 상관없이 요약 주기마다 만들어지고, 옛 메시지는 숨겨져 요약이 대신하며, 최근 N개 메시지는 원문 그대로 남습니다. 이때 원문으로 남아 있는 구간만 다루는 요약은 주입하지 않아 같은 내용이 두 번 들어가지 않습니다.
기록 지연이 0이면 응답이 오자마자 기록합니다. 1 이상이면 그 응답 뒤로 이야기가 N턴 더 진행된 뒤에야 기록해서, 리롤·분석 QR·지운 메시지에 사서 호출을 쓰지 않습니다. 한 턴은 내 답장 또는 새 응답 중 많은 쪽으로 세므로, 인풋 없이 전개지시·풀사칭으로만 진행해도 정상 동작합니다. 새 채팅의 그리팅은 이 값과 상관없이 이야기가 한 턴 진행된 뒤에 기록합니다.

추적 도감

켜면 사서가 대화에서 자동으로 골라내 도감에 기록하고, 매 턴 주입에 포함합니다.

모델 (사서 API)

기억 기록·요약을 담당하는 사서가 쓸 API입니다. 저렴하고 빠른 모델을 권장합니다.

테스트
고급 — 커스텀 헤더/본문

Gemini Thinking·GPT o 시리즈처럼 생각하는 모델을 사서로 쓰면, 사고에 쓴 토큰이 출력 상한을 함께 먹어 응답이 중간에 잘립니다(finishReason: MAX_TOKENS). 서고 정리·요약이 "모델 응답 오류"로 실패한다면 이 값을 12000~16000으로 올려 보세요. 상한일 뿐이라 실제로 쓴 만큼만 과금됩니다. 생각하지 않는 모델을 쓴다면 0으로 둬도 됩니다. (기본 8000)

의미 검색 임베딩 (선택)

임베딩을 켜면 회상 정확도가 크게 올라갑니다. 동의어·의역도 잡아냅니다. 실패 시 자동으로 내장 검색으로 폴백합니다.

실리태번 서버가 임베딩 모델을 직접 돌립니다. 무료·무제한이며 API 키가 필요 없습니다. 처음 사용할 때 모델(수십 MB)을 한 번 내려받느라 잠시 걸릴 수 있습니다.

테스트

OpenAI 계열은 0.35~0.5, bge·e5 계열처럼 점수가 낮게 깔리는 모델은 0.2~0.3이 적당합니다. 회상이 안 되면 낮추고, 엉뚱한 기억이 딸려오면 올리세요. (기본 0.35)

주입 · 검색

주입 깊이는 주입 위치가 "채팅 내"일 때만 쓰입니다. 0이면 마지막 메시지 바로 앞, 숫자가 클수록 위쪽입니다. 채팅 전체보다 앞에 두고 싶으면 9999처럼 채팅 길이보다 큰 값을 넣으세요 — 가장 오래된 메시지 위에 들어갑니다 (최대 10000). 캐릭터 카드·시스템 프롬프트보다도 앞에 두려면 주입 위치를 "메인 프롬프트 앞"으로 바꾸세요.

상태창 · 막간 · 점검

분류

막간은 롤플을 멈추고 뽑은 퀴즈·인터뷰·운세 같은 QR 결과입니다. 지시문에 "롤플·시나리오를 멈춰라"는 문구가 있으면 자동으로 알아보고, 기록·회상·점검에서 뺍니다.

인물과 문체 지키기

요약은 서술자 말투로 쓰이고 옛 원문은 숨겨집니다. 그래서 대화가 길어질수록 캐릭터의 말투가 흐려지고, 옛 문체와 말버릇이 되살아납니다. 아래 설정이 그걸 막습니다.

말버릇

맞추기

서사 시계 재계산

재계산

서고 정리

중복 병합·소음 제거·중요도 변경을 먼저 비교하고 적용합니다. 고정·수동 기억과 서로 다른 비밀 등급·소유자는 병합하지 않습니다. 자동 정리는 검토 없이 실행되며, 변경 전 복구 지점을 남깁니다.

검토

서고 복구 지점

기억 정리·사서 정정·요약 전체 다시 만들기·파일 복원·인계·초기화 직전의 기록을 보관합니다. 최근 3개, 합계 6MB까지 유지하며 대화 원문은 변경하지 않습니다. 오래 보관할 기록은 JSON으로 내보내세요.
