    백업 파일은 어떻게 쓰나요?

    ZIP을 풀면 봇·채팅 이름이 붙은 JSON 파일과 복원 안내가 나옵니다. 해당 채팅을 열고 메모리아 → 도구 → 백업·복원 → 가져오기에서 JSON을 선택하세요. ZIP 자체를 가져오는 방식은 아닙니다.

    메모리아 기억·요약·도감·복구 지점 등을 보관합니다. 대화 원문과 봇 카드는 실리태번에서 별도로 백업해 주세요.

    기억과 요약은 각 채팅의 저장 데이터에 있습니다. 정상적인 확장 업데이트는 이 데이터를 지우지 않습니다. 이 목록은 검사 시점의 현황이며, 백업할 때는 최신 기록을 다시 읽습니다.
